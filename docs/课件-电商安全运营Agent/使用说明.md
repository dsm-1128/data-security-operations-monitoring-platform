# 课件使用说明

双击“项目介绍课件.html”即可离线阅读。请保留同目录下的assets文件夹，或直接解压完整资源包后打开。页面左侧为七章和附录，桌面右侧可检索小节，顶部按钮可打印或另存为PDF。手机窄屏可点击左上角菜单。

“项目介绍课件.md”为完整内容源，六张SVG图可独立插入其他材料。“编写说明.md”记录数据依据与设计边界，“验证”目录保存页面检查结果。

## 内容更新

先编辑Markdown，再运行build.cjs生成HTML与图示。生成器需要Node.js及marked模块；若本机未安装marked，可通过MARKED_MODULE_PATH指定已有marked.esm.js文件路径。阅读生成结果不需要Node.js、服务器或网络。

```powershell
$env:MARKED_MODULE_PATH = '本机marked模块的绝对路径/marked.esm.js'
node ./build.cjs
```

## 尚待补齐的项目资料

成果统计周期、样本量、初筛时间的统计方式、验收依据和验收人尚未提供。日志与身份系统品牌、处置接口、保留策略等按企业实际环境补齐。
